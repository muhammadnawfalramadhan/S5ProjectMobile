# SI-KSP Mobile

Aplikasi Android Sistem Informasi Koperasi Simpan Pinjam (SI-KSP) Afdeling 2 PT BSP.
Versi mobile dari project SI-KSP Web (mata kuliah Rekayasa Perangkat Lunak 2).

## Teknologi
Kotlin · Jetpack Compose · Material 3 · Supabase

## Rencana Fitur
- Login / registrasi anggota & admin
- Dashboard saldo simpanan & pinjaman
- Setor / tarik simpanan
- Pengajuan & verifikasi pinjaman (+ simulasi cicilan)
- Jadwal & pembayaran angsuran + notifikasi jatuh tempo
- Riwayat transaksi & profil
